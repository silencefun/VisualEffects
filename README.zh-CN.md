## 51yifei 精选工具一键直达

每条都直达线上工具页，点开即用：

- [3D 粒子星系](https://51yifei.com/en/visual-effects/three-particle-galaxy/) — Three.js 8000 粒子螺旋星系，鼠标视差交互
- [星座连线](https://51yifei.com/en/visual-effects/constellation/) — 星空粒子连线，鼠标交互绘制星座
- [星空粒子](https://51yifei.com/en/visual-effects/starry-particles/) — 星系星云粒子，旋转闪烁
- [北极光](https://51yifei.com/en/visual-effects/aurora-borealis/) — Canvas 2D 渐变极光动画，动态流动
- [黑洞引力透镜](https://51yifei.com/en/visual-effects/black-hole/) — 黑洞巨大的引力弯曲光线，背景星光被向外拉伸并环绕成爱因斯坦环。
- [文字液态变形](https://51yifei.com/en/visual-effects/text-liquid/) — 文字像水银一样融合分离流动
- [星云生成器](https://51yifei.com/en/visual-effects/nebula-generator/) — 程序化星云生成，体积渲染色彩流动，多种预设
- [3D 动态海洋](https://51yifei.com/en/visual-effects/three-ocean/) — Three.js ShaderMaterial 动态波浪海洋，鼠标制造涟漪
- [体积云](https://51yifei.com/en/visual-effects/volumetric-clouds/) — 用分形布朗运动噪声叠加多层细节，逐像素生成不断翻涌流动的体积云。
- [焦散效果](https://51yifei.com/en/visual-effects/caustics/) — 模拟阳光穿过水面折射，在水底投下不断游动的网状光斑。
- [流场](https://51yifei.com/en/visual-effects/flow-field/) — 无数粒子沿噪声生成的向量场流动，绘出如风或洋流般的丝状轨迹。
- [丁达尔光](https://51yifei.com/en/visual-effects/god-rays/) — 光线穿过缝隙形成放射状体积光束，可拖动光源并切换光色。
- [素数极坐标](https://51yifei.com/en/visual-effects/prime-polar-spiral/) — 将素数映射到黄金角极坐标系上，生成向日葵螺旋花纹，支持动画绘制和配色切换。
- [3D 霓虹隧道](https://51yifei.com/en/visual-effects/three-neon-tunnel/) — Three.js 第一人称霓虹几何隧道穿越
- [爱心粒子计时器](https://51yifei.com/en/visual-effects/heart-timer/) — 由粒子组成的大颗跳动爱心，支持自定义计时与留言
- [天灯](https://51yifei.com/en/visual-effects/sky-lantern/) — 点击放飞发光的孔明灯，升到顶部炸成星光粒子，可自定义心愿
- [点亮蜡烛](https://51yifei.com/en/visual-effects/light-candles/) — 一支支点亮蜡烛，烛光照亮黑暗，全部点亮后呈现祝福与星光
- [鼠标跟随液体](https://51yifei.com/en/visual-effects/mouse-follow-blob/) — 鼠标拖拽产生流体黏连 Blob 特效
- [液态玻璃果冻](https://51yifei.com/en/visual-effects/liquid-glass/) — 类似 iOS 图标的粘性液体果冻效果
- [烟花文字](https://51yifei.com/en/visual-effects/firework-text/) — 烟花爆炸后粒子汇聚成文字，再散开

# Aurora Borealis

Canvas 2D gradient aurora animation, dynamic flow

![Aurora Borealis preview](demo.gif)

## Run it

Open `index.html` in any modern browser — no build, no install, no dependencies.

```bash
# just open it
open index.html
```

## How it works

Several vertical gradient curtains are drawn with per-column noise offsets and additive blending, which is enough to fake a flowing, breathing aurora.

The full implementation, controls and edge cases live on the live site — the snippet above is the core idea only.
